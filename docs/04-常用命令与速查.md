## 常用命令

```bash
# 运行
dotnet run --project src/OrderManagement.Api

# EF Core 迁移
dotnet ef migrations add <名称> --project src/OrderManagement.Api
dotnet ef database update --project src/OrderManagement.Api
dotnet ef migrations remove --project src/OrderManagement.Api   # 尚未 update 时可撤销
dotnet ef migrations script --idempotent                        # 多环境发布脚本（DEV→UAT→PRD）

# 用户机密（JWT 配置，仅本地开发）
dotnet user-secrets list --project src/OrderManagement.Api
dotnet user-secrets set "Jwt:SecretKey" "<value>" --project src/OrderManagement.Api

# 测试
dotnet test tests/OrderManagement.Tests/OrderManagement.Tests.csproj
dotnet test --configuration Release                             # CI 同款（配合 --no-build）

# 代码质量
dotnet format OrderManagement.slnx --verify-no-changes --no-restore
dotnet list OrderManagement.slnx package --vulnerable --include-transitive   # 漏洞扫描
dotnet nuget why src/OrderManagement.Api/OrderManagement.Api.csproj <包名>   # 传递依赖链

# Docker
docker compose up -d --build
docker compose ps -a
docker logs order-api
docker compose config -q                     # 预检 compose 配置
# ⚠️ 严禁 docker compose down -v（会删数据卷！）
```

## 验证路径速查

| 想验证什么 | 请求 |
| --- | --- |
| 分页查询 | `GET /api/orders?pageIndex=1&pageSize=10` |
| 订单详情（缓存） | `GET /api/orders/{id}` —— 连续两次看日志 Miss→Hit |
| 全局异常 + 日志 | `GET /api/orders/test-error` → 看 `logs/order-yyyyMMdd.log` |
| DI 生命周期 | `GET /Lifecycle`（Transient1≠Transient2、Scoped1=Scoped2、Singleton1=Singleton2） |
| Options 三种接口 | `GET /api/OptionsExperiment` |
| 配置读取 | `GET /api/Settings` |
| JWT 登录 | `POST /api/auth/login` `{"username":"admin","password":"123456"}` |
| 需登录接口 | `GET /api/orders/secure`（带 `Authorization: Bearer <token>`） |
| 角色接口 | `GET /api/orders/admin`（Admin token 200 / User token 403） |
| 乐观并发 409 | 用旧 Version `PUT /api/orders/{id}` → 409 Conflict |
| 限流 429 | 1 分钟内对 `/api/orders` 请求超过 5 次（Testing 环境放宽到 1000） |
| 健康检查 | `GET /health/live`（进程）、`GET /health/ready`（PG + Redis） |

## CI / 部署速查

```bash
# GitHub Actions（.github/workflows/dotnet-ci.yml）
# push / PR 到 main → restore → build(Release) → test

# Compose 三件套
docker compose up -d --build          # postgres + redis + api
docker compose logs -f api            # 看启动日志（当前环境: Production）
curl http://localhost:8080/health/ready

# 数据备份（迁移前必做）
docker exec order-postgres pg_dump -U postgres -d OrderManagementDb > ordermanagement-backup.sql
```
